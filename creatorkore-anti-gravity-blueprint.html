The Core Workflow (5-Step Pipeline)

The exact system for building Apple-style animated websites using entirely free Google AI tools. Each step builds on the previous one.

1
Google Whisk — Generate "before" and "after" frames

Create the starting frame (clean product) and ending frame (product exploding/splashing/assembling) using reference images and Whisk prompts.

2
Google Flow (Veo 3.1) — Animate between frames

Upload start + end frames into Frame-to-Video mode. Use a cinematic transition prompt. Generate at highest quality (upscaled).

3
EZGif — Convert video to image sequence

Upload the generated video to EZGif.com. Use Video-to-JPG converter. Extract all frames (usually ~80-170 frames). Download as zip.

4
Anti-Gravity — Build the scroll-animated website

Open the frames folder in Anti-Gravity. Use the "1-Click" Web Gen Prompt. Select Gemini 3.1 Pro in Planning mode. AI generates full Next.js website with scroll-triggered frame animation.

5
Netlify — Deploy for free

Prompt Anti-Gravity to create a static build (npm run build → /out folder). Drag-and-drop the out folder onto Netlify for instant deployment with a free URL.

Prompt Library (from the Skool Community)

1. End Frame Prompt (for Google Whisk)

Copied from the Skool community and adapted via Gemini to match your specific product:

"Elegant [product] wrapped in [material], [action] everywhere, [lighting], high definition resolution, cinematic quality"

Process: Paste the generic prompt into Gemini → ask it to adapt the prompt to your specific product image → use the adapted prompt in Google Whisk with your starting image as reference.

2. Transition Prompt (for Google Flow / Veo 3.1)

Used in Frame-to-Video mode between your start and end frames:

"Smooth cinematic transition showing [product] unwrapping and exploding with [ingredients/particles], dynamic camera movement, premium quality"

Settings: Veo 3.1 quality mode (not fast). Download upscaled version.

3. Web Gen Prompt (for Anti-Gravity — "1-Click" Build)

The core prompt from the Skool community that generates the complete website. Adapt via Gemini to your product:

"Build a premium animated website for [product name]. Use the images in the /images folder as a scroll animation sequence. - The animation should play forward as the user scrolls down - It should be the hero section background - Smooth frame transitions synced to scroll position Style: - Dark theme with [accent color] accents - Modern, minimalist, Apple-like design - Full-screen hero with centered content overlay - Glass morphism cards for feature sections Sections: 1. Hero: Full-screen with scroll animation background, headline, CTA 2. Features: 3-4 glass cards with icons 3. Stats: Animated counters 4. How It Works: Numbered steps 5. Gallery: Image showcase 6. CTA: Final conversion section Make it responsive and premium."

Settings: Gemini 3.1 Pro model, Planning mode (not Fast).

4. UI Polish Prompt

After initial build, take a screenshot of a reference design and feed it back:

"The animation works great. Now polish the UI to match this reference design [attach screenshot]. Improve typography, spacing, colors, and overall visual hierarchy."

5. Full Structure Prompt

After the hero animation is built, extend to full page:

"Build out all remaining sections of the website now. Use the same consistent style. Include: - Hero (already done — keep animation) - Features section with glass cards - Stats with animated counters - How It Works with numbered steps - Gallery / portfolio grid - Testimonials - FAQ - Final CTA - Footer"

6. Deployment Prompt (Netlify)

"I want to host this on Netlify as a static site. Give me the build command and output folder."

Result: Anti-Gravity generates an /out folder. Drag and drop onto Netlify's manual deploy area for a free live URL.

Custom Rules for Anti-Gravity Agent

Set these in Anti-Gravity → Settings → Agent Settings → Custom Rules for consistent output:

  • Always use semantic HTML5 elements for better accessibility and SEO
  • Maintain consistent spacing using an 8px grid system throughout the design
  • All animations should respect prefers-reduced-motion for accessibility
  • Use CSS variables for all colors to enable easy theme switching

Complete Anti-Gravity Workflow Summary

Phase 1: Asset Creation (Steps 1-3)

  1. Find reference images of top brands in your niche
  2. Open Anti-Gravity, create project folder, set custom rules
  3. Use Google Whisk to generate start frame (clean product) + end frame (product in action)
  4. Upload both frames to Google Flow (Veo 3.1) with cinematic transition prompt
  5. Download upscaled video → convert to JPG frames via EZGif
  6. Extract zip → open folder in Anti-Gravity

Phase 2: Website Build (Steps 4)

  1. Paste Web Gen Prompt adapted to your product
  2. Set Gemini 3.1 Pro, Planning mode
  3. Generate — AI builds full Next.js site with scroll animation
  4. Polish UI by feeding reference design screenshots
  5. Prompt to build remaining sections (features, stats, how-it-works, gallery, FAQ, CTA)
  6. Add extras: dark/light mode toggle, testimonial carousel, etc.

Phase 3: Deploy & Monetize (Step 5)

  1. Prompt Anti-Gravity to create static production build
  2. Run npm run build in terminal → /out folder is created
  3. Go to Netlify → Add new site → Deploy manually
  4. Drag-and-drop the /out folder → site goes live in seconds
  5. Optionally add custom domain via Netlify Domain Management
